# Base64 Codec 插件

dinotty 插件，提供 Base64 编码与解码工具，完整支持中文等非 ASCII 字符（UTF-8）。

## 功能

- **编码**：任意文本 → Base64（UTF-8 安全，中文不乱码）
- **解码**：Base64 → 文本，自动兼容标准 / URL-safe 变体，忽略输入中的空白
- **URL-safe 模式**：`-`/`_` 替换 `+`/`/`，去除 `=` 填充（RFC 4648 §5）
- **互换**：一键交换输入/输出，方便反向操作
- **回填**：将输出回填到输入，支持链式操作
- **剪贴板操作**：一键粘贴输入、复制输出
- **错误提示**：非法 Base64 或非法 UTF-8 序列详细显示
- **统计信息**：输入/输出的字符数和字节数

```
│  输入   12 字符 · 12B │  输出   16 字符 · 16B       [复制]    │
│  [粘贴] [清空]       │                                       │
│                      │                                       │

│  [编码 →]            │                                       │

│  [⇅ 互换] [← 回填]   │                                       │
└──────────────────────┴───────────────────────────────────────┘
```

## 安装

无需构建步骤，直接在 dinotty 插件管理器中安装，或手动链接：

```bash
ln -s $(pwd) ~/.dinotty/plugins/base64-codec
```
